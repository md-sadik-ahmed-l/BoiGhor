# BoiGhor – Library Study Room Booking

## Live Site: 

StudyNook is a full-stack web application where students and library users can browse, book, and manage study rooms easily. Users can list their own study rooms, manage bookings, and prevent double-booking through smart time conflict detection.


##  Features

-  Secure JWT Authentication with HTTP-only Cookies
-  Browse and Search Available Study Rooms
-  Add, Update, and Delete Personal Room Listings
-  Smart Booking System with Time Conflict Detection
-  Prevents Double Booking for Same Time Slots
-  Automatic Booking Cost Calculation
-  Manage Personal Bookings and Listings
-  Cancel Bookings with Status Update
-  Fully Responsive for Mobile, Tablet, and Desktop
-  Beautiful Toast Notifications and Loading States

##  Room Management

Authenticated users can:

- Add New Study Rooms
- Update Room Information
- Delete Their Own Rooms
- Manage Room Amenities
- View Booking Counts


##  Booking Features

- Book Rooms by Date & Time
- Real-Time Booking Conflict Prevention
- Automatic Total Price Calculation
- Cancel Upcoming Bookings
- Booking Status Tracking


##  Search & Filter

Users can:

- Search rooms by room name
- Filter by amenities
- Filter by floor
- Filter by hourly price range
